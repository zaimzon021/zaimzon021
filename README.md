## 🔧 Flagship open-source work

* **[mongo-tenant-guard](https://github.com/zaimzon021/mongo-tenant-guard)** — Fail-closed multi-tenant isolation for MongoDB in TypeScript. Every query is forced to carry a `tenantId`, or it does not run.
* **[mongo-transact](https://github.com/zaimzon021/mongo-transact)** — Safe, retrying MongoDB transactions for Node.js: automatic session lifecycle, transient-error retries, and timeouts.

Both are MIT licensed, tested, and built for the same problem space: SaaS backends where a forgotten filter or a half-committed write can leak or corrupt customer data.
